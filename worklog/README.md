# Worklog

Worklogs record execution process, observations, and unresolved questions by date. They do not replace task status, run manifests, or factual changelog entries.

- Task status: `tasks/<task-id>-<slug>.md`
- Formal run provenance: `runs/<run-id>/manifest.json`
- Result interpretation: `reports/<task-id>/`
- Project-level interpretation: `PROGRESS.md`
