# Alternating quadratic convergence: open derivation

**Status: Conjecture and proof worklist.**

Consider coupled strongly convex quadratics with shared variable \(\theta\) and
private variables \(\phi_i\). The next formal derivation must:

1. write the block Hessian and optimum;
2. derive the exact linear error recursion for simultaneous gradient descent;
3. derive the shared-then-private Gauss--Seidel recursion;
4. derive private-then-shared and exact Schur-reduced recursions;
5. state stable step-size regions;
6. compare spectral radii;
7. retain examples where each method wins.

No project document may cite a general convergence speedup until this file is
replaced by a complete theorem with assumptions and counterexamples.
